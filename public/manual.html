Aria Medical Caller Lookup

User manual

Use this guide to install the desktop application, prepare organization data, and support staff during day-to-day caller lookup operations.

Install

Getting started

  • Download the newest production build from the latest release page.
  • Install the application using your normal desktop deployment process.
  • Confirm that your organization directory or import source is available.

Daily use

Lookup workflow

  • Launch the app and load the current organization contact dataset.
  • Search by organization, department, or staff member to find contact details.
  • Share verified contact information with the caller or internal care team.

Support

Troubleshooting

  • Update to the latest release when users report outdated data or missing fixes.
  • Verify data imports and source file access if lookups return incomplete results.
  • Escalate persistent application errors through your normal Aria Medical support path.

Operations

Deployment checklist

  • Confirm desktop prerequisites on every workstation before rollout.
  • Distribute the manual link alongside the application installer.
  • Review staff onboarding steps after every published release.
